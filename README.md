# Energia EE Daily PWA

Parandatud versioon:
- Uuendab andmeid 1x päevas ja salvestab tulemuse brauserisse.
- Graafik näitab tänast ja homset Eesti elektrihinda, kui homsed hinnad on avaldatud.
- Nupust ↻ saab sundida uut päringut.
- Failid peavad GitHub repository juurkaustas olema: index.html, manifest.webmanifest, sw.js, README.md ja icons/.

Pärast üleslaadimist tee brauseris Ctrl+F5 või mobiilis kustuta sait cache'ist, sest service worker võib vana versiooni hoida.
